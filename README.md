# Calvi_phone

Мобільний застосунок, Flutter. iOS + Android.

## Стан

Каркас піднято. Токени, тема, шрифт і перевірка обох тем на місці.
Екранів ще немає: усе, що видно зараз, це стенд у `main.dart`, який доводить,
що фундамент несе те, на чому зійшлося демо. Він зникає з першим справжнім екраном.

## Токени не пишуться руками

`lib/design/tokens.dart` **згенерований**. Джерело одне і воно в демо:
`Demo_Flutter/src/styles/tokens.css`. Там значення видно на екрані, там про
нього можна сперечатися, звідти воно й їде сюди.

```bash
node tools/tokens.mjs
```

Правка `tokens.dart` руками розводить застосунок і демо, а генератор існує рівно
для того, щоб цього не сталося.

## Кольори через тему, не через імпорт

`context.c.protein`, а не `calviLight.protein`. Віджет, який тягне палітру
імпортом, ігнорує темну тему, і помилку не видно, поки хтось не перемкне.
