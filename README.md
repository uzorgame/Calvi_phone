# Calvi

Трекер калорій із помічником. Людина пише або каже, що з'їла, звичайними
словами, а застосунок сам розбирає це на страву, вагу і числа. Flutter, Android
і iOS.

## Запуск

Потрібен Flutter із Dart 3.10 або новішим: у `pubspec.yaml` і
`analysis_options.yaml` є два обходи, писані саме під цю версію, і на старшому
аналізаторі вони дають фантомні помилки.

```bash
flutter pub get
flutter run
```

Без свого сервера застосунок відкривається в режимі «демо»: показовий день із
готовими числами, на якому видно всі екрани. Свій сервер підставляється так:

```bash
flutter run --dart-define=CALVI_API=https://your.server
```

Тести:

```bash
flutter test
```

## Що всередині

`lib/screens` це екрани: день, аналітика, препарати, налаштування, старт,
камера, голос. `lib/data` це моделі, локальна база на drift і зв'язок із
сервером. `lib/design` це тема, токени, спільні віджети.

Розмова з помічником, розбір тексту й фотографій ідуть через окремий сервіс:
ключа моделі в застосунку немає і не буде.

## Що згенероване, а не написане

Ці файли пише генератор, і правити їх руками означає розвести застосунок із його
джерелом:

- `lib/design/tokens.dart` — кольори й розміри, джерело в CSS демки;
- `lib/design/icons.dart` — набір іконок;
- `lib/data/allergens.dart` і `lib/data/legal.dart` — довідник алергенів і
  юридичні тексти;
- `lib/l10n/` — переклад, джерело в `l10n/` поруч;
- `*.g.dart` — код drift, перезбирається `dart run build_runner build`.

Самі генератори живуть у робочому репозиторії проєкту разом із демкою, з якої
вони читають. Тут лежить уже згенероване.

## Кольори через тему, не через імпорт

`context.c.protein`, а не `calviLight.protein`. Віджет, який тягне палітру
імпортом, ігнорує темну тему, і помилку не видно, поки хтось не перемкне.
